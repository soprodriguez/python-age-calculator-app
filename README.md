# Age Calculator (Python GUI)

## Description

This project is a simple Age Calculator application built using Python and Tkinter. It provides a graphical user interface (GUI) where users can enter their name and birth date (year, month, and day). After clicking the "Calculate Age" button, the program calculates and displays the user’s age in years.

## Features

* User-friendly GUI built with Tkinter
* Input fields for name, birth year, month, and day
* Calculates age based on current date
* Displays personalized result message
* Simple and beginner-friendly design

## Technologies Used

* **Python**
* **tkinter** (for GUI development)
* **datetime** (for age calculation)

## Requirements

* Python installed on your system
* tkinter (comes pre-installed with most Python distributions)
* datetime (built-in Python module)

## How to Run the Program

1. Save the code in a Python file (e.g., `age_calculator.py`).
2. Open your terminal or IDE.
3. Run the program:

   ```
   python age_calculator.py
   ```
4. Enter your name and birth date in the fields.
5. Click **"Calculate Age"** to see your result.

## Example Output

* Input:

  * Name: John
  * Birthdate: 2000 / 5 / 10
* Output:

  * "John your age is 24.00 years old"

## Notes

* The program calculates age by subtracting the birth date from the current date.
* Age is displayed in years (rounded to two decimal places).
* This project is ideal for beginners learning GUI development in Python.
